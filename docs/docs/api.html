Library and API.

A practical map of the functions and types available to a game today. Expand a method for its purpose and contract.

Foundation API: Emergent is evolving quickly. This guide records the checked-in 0.10.0 API; it does not promise long-term semantic version stability yet.

Engine lifecycle

Engine

Owns the world, schedules, tick counter, fixed-step accumulator, and exit state.

Game

Lifecycle trait with start, required fixed_update, after_fixed_update, and stop.

EngineConfig

Configures fixed timestep, maximum frame delta, catch-up step limit, and idle sleep.

EngineContext

Provides mutable world access, current tick, fixed delta, and exit control during callbacks.

Engine::newCreate an empty engine
pub fn new(config: EngineConfig) -> Result<Self, EngineError>

Rejects a zero fixed timestep or zero catch-up limit.

Engine::runRun against wall-clock time
pub fn run<G: Game>(&mut self, game: &mut G) -> Result<(), EngineError>

Starts the game, advances bounded fixed steps until exit is requested, sleeps briefly between steps, then calls stop.

Engine::run_ticksAdvance exact headless ticks
pub fn run_ticks<G: Game>(&mut self, game: &mut G, ticks: u64) -> Result<(), EngineError>

Does not sleep or read the clock. Useful for tests, tools, replay, and deterministic headless execution.

Engine::start / advance_frame / stopIntegrate an external platform loop
start(&mut self, game) · advance_frame(&mut self, game, elapsed) · stop(&mut self, game)

advance_frame returns FrameAdvance { fixed_steps, catch_up_limited }. The visible window example uses this API.

Engine::world / world_mutAccess the authoritative world
pub fn world(&self) -> &World
pub fn world_mut(&mut self) -> &mut World
Engine::schedule_mutRegister Bevy systems
pub fn schedule_mut(&mut self, phase: SchedulePhase) -> &mut Schedule

Phases are PreFixed, Fixed, and PostFixed.

World and entities

World owns canonical SlotMap entity and behaviour storage plus private Bevy ECS component storage. EntityId is world-scoped and generational.

World::new / with_capacityCreate canonical storage
pub fn new() -> Self
pub fn with_capacity(capacity: usize) -> Self

Reserve when expected entity count is known to reduce setup reallocations.

World::spawnCreate a root entity
pub fn spawn(&mut self, name: impl Into<String>) -> EntityId
World::spawn_childCreate and parent an entity
pub fn spawn_child(&mut self, parent: EntityId, name: impl Into<String>) -> Result<EntityId, WorldError>
World::get / parent / childrenInspect hierarchy
get(id) -> Result<&Entity, WorldError>
parent(id) -> Result<Option<EntityId>, WorldError>
children(id) -> Result<Vec<EntityId>, WorldError>

Entity::name returns the diagnostic name. The children vector is a copied snapshot.

World::reparentMove a subtree
pub fn reparent(&mut self, entity: EntityId, new_parent: Option<EntityId>) -> Result<(), WorldError>

Retains local transform, rejects hierarchy cycles and cross-world handles, then dirties the moved subtree.

World::remove_subtreeDelete owned descendants
pub fn remove_subtree(&mut self, root: EntityId) -> Result<usize, WorldError>

Iteratively removes the root, descendants, their ECS mappings, and owned behaviours. Stale handles do not alias replacement objects.

World::len / is_emptyCount live entities
pub fn len(&self) -> usize · pub fn is_empty(&self) -> bool

Transforms

Transform stores local translation, quaternion rotation, and scale. GlobalTransform stores the propagated affine result.

TransformConstruct local transforms
Transform::new(translation, rotation, scale)
Transform::from_translation(value)
Transform::from_rotation(value)
Transform::from_scale(value)

Inputs must be finite; rotation must be normalized and scale must be non-zero.

World::set_local_transformUpdate and dirty a subtree
pub fn set_local_transform(&mut self, id: EntityId, transform: Transform) -> Result<(), WorldError>
World::local_transform / global_transformRead transform state
local_transform(id) -> Result<&Transform, WorldError>
global_transform(id) -> Result<&GlobalTransform, WorldError>

GlobalTransform provides translation, transform_point, and matrix.

World::propagate_transformsCommit global transforms
pub fn propagate_transforms(&mut self) -> PropagationStats

The normal engine tick invokes propagation automatically. Manual worlds can call it explicitly.

Behaviours are SlotMap-owned nodes linked through typed ports. Evaluation reads the previous committed snapshot, stages outputs and transform writes, then commits together.

Components, resources, and schedules

Emergent re-exports bevy_ecs and its Component derive. Canonical entity lifecycle remains controlled by World.

World::insert_component / component / component_mutAccess game components
insert_component<T: Component>(id, value)
component<T: Component>(id)
component_mut<T: Component>(id)

The internal Bevy entity is never exposed. EntityIdentity is protected engine state.

World::insert_resource / resource / resource_mutAccess Bevy resources
insert_resource<R: Resource>(value) · resource<R>() · resource_mut<R>()
EntityLifecycleQueueRequest structure changes from systems

Scheduled systems call spawn, spawn_child, or remove_subtree on the queue. Results appear in order through EntityLifecycleResults after commit.

Graphics preview

CPU geometry values are available in headless builds. GeometryRenderer is enabled by features = ["graphics"] and owns uploaded GPU buffers through renderer-scoped, typed SlotMap handles.

Point

Finite position, positive radius, and colour. Rendered as a solid octahedral marker.

Line

Distinct finite endpoints, positive radius, and colour. Rendered as a solid square prism.

Polygon

Ordered, planar, strictly convex vertices and colour. Triangulated as a fan.

Mesh

Validated MeshVertex values and 32-bit triangle indices. Includes Mesh::cube.

Primitive

Validated plane, cuboid, pyramid, sphere, cylinder, cone, capsule, or torus parameters with deterministic to_mesh generation.

PrimitiveKind

Stable shape-family inspection without exposing unchecked enum fields or bypassing construction validation.

GeometryRenderer::newInitialize renderer-owned geometry storage
pub async fn new(window: Arc<Window>, display: OwnedDisplayHandle) -> Result<Self, GraphicsError>

Selects a surface-compatible adapter and creates the depth-tested colour pipeline, dynamic instance-uniform storage, and empty typed SlotMap.

GeometryRenderer::insert / insert_with_shadingManage uploaded geometry
insert(&mut self, geometry: &Geometry) -> GeometryId
insert_with_shading(&mut self, geometry: &Geometry, mode: ShadingMode) -> GeometryId

insert uses smooth normals. ShadingMode::Flat expands each indexed triangle during upload so all three vertices carry the same geometric face normal. GeometryId remains generational and renderer-scoped.

GeometryRenderer::render / render_litDraw copied geometry instances
render(&mut self, instances: &[GeometryInstance])
render_lit(&mut self, instances: &[GeometryInstance], lights: &[LightInstance])

render keeps unlit colour output. render_lit validates at most eight copied lights, evaluates Lambert illumination, and lets the first enabled directional request use a fixed 2048-square comparison shadow map.

Primitive constructorsGenerate bounded mesh sources
Primitive::plane · cuboid · cube · pyramid
Primitive::sphere · cylinder · cone · capsule · torus
Primitive::to_mesh() -> Result<Mesh, GeometryError>

Dimensions must be finite and usable. Segment and ring counts have shape-specific lower bounds and a common upper bound of 512 per subdivision axis.

GeometryRenderer::resize / infoMaintain and inspect the surface
resize(&mut self, size: PhysicalSize<u32>)
info(&self) -> &RendererInfo

Zero-sized surfaces are ignored. Non-zero changes recreate the depth target. Adapter, backend, and format remain inspectable.

CubeRendererCompatibility wrapper

The original API remains available and delegates to one GeometryRenderer resource created from Mesh::cube.

Lighting declarations

A light is a canonical entity carrying a validated LightSource ECS component. Copy it with its propagated transform into LightInstance after simulation, then call render_lit. The first renderer accepts eight lights and one selected directional shadow caster.

LightSource

Private validated light data containing kind, colour, intensity, optional range/cone, and shadow-casting intent.

LightKind

Ambient, directional, point, or spot. Spatial kinds derive position or negative-Z direction from the entity transform.

LightInstance

Copied per-frame source and model data. It carries no durable or renderer-owned identity.

ShadowCasting

Enabled directional requests compete in supplied order; only the first becomes the current shadow caster. Point and spot shadows remain future work.

LightSource constructorsCreate validated light components
LightSource::ambient(color, intensity)
LightSource::directional(color, intensity)
LightSource::point(color, intensity, range)
LightSource::spot(color, intensity, range, inner_half_angle, outer_half_angle)

Intensity is finite and non-negative. Ranges are finite and positive. Spot half-angles are ordered and no wider than 90 degrees.

LightSource::with_shadow_castingDeclare shadow intent
with_shadow_casting(ShadowCasting) -> Result<LightSource, LightError>

Ambient lights reject shadow casting. Other kinds retain the request for future render extraction.

Project contract

Project loads a versioned emergent.toml without constructing runtime entities. Authored IDs and paths remain separate from SlotMap and ECS keys.

Project::loadLoad and validate a project root
pub fn load(root: impl AsRef<Path>) -> Result<Self, ProjectError>

Validates schema version, identifiers, portable paths, containment, declared roots, entry scene, generated-code directory, unique output IDs, and at least one enabled output.

Project::manifest / root / entry_scene_pathInspect resolved project metadata
manifest(&self) -> &ProjectManifest
root(&self) -> &Path
entry_scene_path(&self) -> PathBuf
Project::enabled_outputsInspect selected output declarations
pub fn enabled_outputs(&self) -> impl Iterator<Item = &ProjectOutput>

Outputs report target OS, architecture, Rust target triple, profile, and selection. Packaging is not implemented yet.

Project::asset_path / read_asset / read_text_assetResolve project-owned assets
asset_path(relative) -> Result<PathBuf, ProjectError>
read_asset(relative) -> Result<Vec<u8>, ProjectError>
read_text_asset(relative) -> Result<String, ProjectError>

Paths must fall under a declared asset root and resolve within the project root.
