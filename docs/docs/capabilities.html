Preview

Terrain Builder

IDE previews for Hilly, Mountainous, Rivers and Island terrain. Adjust seed, shape, resolution and major mountain count, then orbit an untextured grayscale mesh under directional sunlight. Roughness uses a 0–1 slider. Compare Perlin, diamond-square and an enhanced Rust pipeline with domain warp, multi-summit mountain massifs/ridges and thermal erosion. Explicit version-1 recipes retain their old terrain. Per-result preparation timings and output sizes are visible. Save the displayed recipe to a named terrain asset and instance in the active scene, with optional terrain collision. Water and hydraulic erosion remain planned.

Preview

Device & mixer

Default output through cpal (macOS verified), a lock-free, allocation-free mixer, bus gains, music ducking under speech, a send reverb, an output limiter and 32 real voices with quietest-first virtualisation. Device selection and per-bus effects remain planned.

How to read status

StatusMeaningSafe assumption
AvailableImplemented and covered by the current validation suite.Use the documented public API.
PreviewRunnable implementation with a deliberately narrow contract or incomplete platform evidence.Experiment and expect change.
PlannedNamed engine responsibility with intended ownership and dependencies; no runtime API is implied.Use it for planning and avoid generated calls to it.
