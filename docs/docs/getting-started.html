GuideGetting started

From checkout to first tick

Get Emergent running.

You need a stable Rust toolchain. The default command runs the headless behaviour demo; one feature flag enables the first native graphics path.

Prerequisites

  • Install Rust with rustup

    Use the installer from rustup.rs, then open a new terminal.

    Terminal
    rustc --version
cargo --version

  • Open the repository

    All commands in this guide assume the project root as the current directory.

    Terminal
    cd /Users/iansorbello/dev/emergent

  • Run the headless reference game

    This compiles the lightweight core, advances 120 fixed ticks, and prints the linked leader/follower positions.

    Terminal
    cargo run --release

Open the first 3D window

The optional graphics feature compiles winit, wgpu, and the small renderer. The first build takes longer because it adds the native graphics stack.

Terminal
cargo run --release --features graphics --example first_window

A window titled Emergent — First wgpu object displays a rotating coloured cube. Resize it to exercise surface and depth-target recreation, then close the window normally.

Automated smoke mode: append -- --smoke. The example requests a resize, renders for 120 simulation ticks, reports the adapter/backend, and closes itself.

Render the geometry gallery

The gallery uses public geometry models and renderer-owned SlotMap handles to draw a point, line, convex polygon, and custom indexed mesh with bounded ambient/directional lighting and the first directional shadow pass.

Terminal
cargo run --release --features graphics --example geometry_gallery

Each shape belongs to a canonical Emergent entity. The frame extracts its copied global matrix into a GeometryInstance. Use -- --smoke to resize, present 120 fixed ticks, and exit automatically.

Generate procedural primitives

The primitive gallery constructs eight parameterized shapes through headless APIs, converts them to validated indexed meshes, uploads each once, and renders their entity transforms.

Terminal
cargo run --release --features graphics --example primitive_gallery

The gallery includes a plane, cube, pyramid, UV sphere, cylinder, cone, capsule, and torus. Append -- --smoke for the self-closing validation run.

Check the engine

Run the default tests for the headless core. Before committing engine work, also check every target and optional feature.

Terminal
cargo fmt --check
cargo test
cargo test --release --all-features
cargo clippy --all-targets --all-features -- -D warnings

Use the library from a local game crate

Emergent is currently developed as a local engine project rather than a published crates.io package. Point a game crate at its checkout:

Cargo.toml · headless
[dependencies]
emergent = { path = "../emergent" }
Cargo.toml · with graphics
[dependencies]
emergent = { path = "../emergent", features = ["graphics"] }
Reference project: run cargo run -p emergent-first-project to validate and launch the checked-in independent game package. Its generated Rust uses the public API; automatic authored-scene expansion remains planned.
