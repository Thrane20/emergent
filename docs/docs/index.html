GuideIntroduction

Build from entities. Compose behaviour.

A small engine with explicit foundations.

Emergent is a Rust game engine built around SlotMap identity, entity hierarchies, fixed simulation, typed behaviour links, and an optional wgpu renderer. This guide shows what exists today and how to use it.

How the pieces fit

Identity and ownership stay in the SlotMap world. Dense component work stays in Bevy ECS. Rendering consumes copied values after simulation, so GPU resources never become entity identity.

GameYour Game callbacks, components, systems, scenes, and behaviour composition.
SimulationFixed ticks, behaviour snapshots, lifecycle commit, and transform propagation.
WorldSlotMap entity and behaviour identity, hierarchy ownership, plus Bevy component storage.
PlatformOptional winit events and wgpu presentation fed by copied render data.
Canonical identity: use EntityId and BehaviorId while objects are alive. SlotMap keys are runtime handles and are not durable save-file or network identifiers.
