# Sprite API quality investigation — 2026-10-30

## Verified evidence

The reported Animation2 asset was generated by `fal-ai/wan/v2.2-5b/image-to-video`. Its retained MP4 contains the same intermittent colour blocks as its atlas. A fresh read-only retrieval of fal's stored output was byte-identical: 399686 bytes, SHA256 `4de09348e37a3d29259a0fbccc1288386abb3e07fca46acae4e7e5f6e80295a6`. The uploaded editor source was byte-identical to the local static PNG. No decoder errors were reported by ffmpeg.

Read-only fal request history revealed the successful website request `01a189dd-2d31-72c0-8939-3d3fb13e273d`, matching the user-provided output (651170 bytes, seed10127565). Frame extraction from this clip is clean. Its actual output is 768x768, while the faulty request returned 512x512. The website source upload is a 192x192 RGBA PNG, while the editor uploaded the original 1024x1024 PNG; the website image closely matches a resized original (RGB SSIM0.9913 at512x512). This is not a controlled same-input/seed experiment.

The editor sent 580p, an appended VFX prompt, a hidden negative prompt, and interpolation disabled. The website sent the original user prompt, 720p, 40 inference steps, CFG3.5, shift5, film interpolation with zero inserted frames, high output quality and balanced encoding. Seeds also differed. These differences are verified; attributing the visible artifact to any single parameter is not established.

## Changes and recovery

- Default Wan requests now preserve the user-entered prompt exactly, omit the hidden negative prompt, and explicitly use the website's quality parameters. Existing input and output safety checks remain enabled. The website request had output safety checking disabled; that difference is deliberately retained.
- Sprite options now exposes the animation seed, validates its integer bounds and passes it to the existing media job. It can be set to10127565 for a comparison attempt.
- Downloaded the already-generated clean website clip and passed it through the existing local atlas bake/import path. No model was submitted. Added a separate family variant at `assets/textures/44a62c8a-6cac-42a6-8334-7960a18e9c8e/Particle sprite website recovery.png` with request/settings/seed provenance. The static image and faulty variant were preserved. This is a recovery from the clean output, not a repaired reconstruction of corrupted frames.
