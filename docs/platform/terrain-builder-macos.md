# Terrain Builder — macOS evidence

2026-10-25, Apple M3 Pro, native Rust noise generation and Chrome browser.

- Workspace Rust tests, release/all-features tests, strict Clippy, rustdoc and
  formatting passed after the headless noise bridge gained candidate-only support.
- 47 IDE tests, lint, TypeScript and production build passed. Tests cover input
  bounds, deterministic/distinct shaping, island edges/river valleys, unit normals,
  positive-Y triangle winding, grayscale vertices and self-contained GLB output.
- `EMERGENT_IDE_BASE_URL=http://localhost:3001 pnpm --filter emergent-ide test:terrain`
  passed on a temporary production server. All four presets were generated by
  Rust and loaded in the viewer. Equal seeds matched; a changed seed differed.
  Browser drag orbit, wheel zoom, reset, error recovery and 600px layout passed.
- The shared viewer now handles models already loaded before effect registration,
  preventing a stale Loading label on fast local previews.

No project files or provider requests were used by the browser check. The tool is
non-persistent and produces an ephemeral preview GLB. No runtime terrain or frame
budget claim, and no Windows/Linux/Safari runtime evidence. Saving, scene placement,
physics, chunking/LOD and water/erosion are deferred.

## Directional sunlight and spaced mountain peaks

The follow-up passed 48 IDE tests, lint, TypeScript and production build. Mountain
region tests cover counts 1, 3, 8 and 12 at zero roughness; identical seeds match
and alternate seeds move the peaks. A native browser run checks the Mountain count
input, keyboard-operated roughness slider/readout and submitted values. It verifies
one directional light in the loaded GLB, disables that light, compares rendered
canvas output, then restores it. Orbit/zoom/reset and failure retention still pass.
Mountain footprints are seeded, elliptical and rotated; noise adds restrained detail
rather than turning every noise contour into a ridge. No project files changed.

## Visible sun controls and ambient contrast correction

49 IDE tests, lint, TypeScript and production build passed. Browser smoke verifies
Sun strength/direction/elevation slider values reach the generated light, and
compares the actual model canvas with that light enabled/disabled. In this fixture
(strength 1), average opaque-pixel brightness was approximately 155 enabled and
26 disabled on a 0–255 scale. The test requires a clear brightness difference and
readable dim ambient fill. These are fixture checks, not universal visual targets.
The four presets, orbit/zoom/reset, failure recovery and narrow layout still pass.
